A LITTLE HELP TO START

从哪里开始？
按你的兴趣来。

想学习，想玩一会儿，
还是只是随便看看，都有一个入口。

想体验学习和效率工具？

复习教材，可以打开多书知识问答台：本地检索与 DeepSeek 在线回答相结合，生成失败会回退原文。在线回答会发送问题与相关知识点，使用前可阅读页面说明。写笔记可以安装 Note to Site，将笔记转换为文章 HTML。

哪些游戏现在就能玩？

游戏页提供六款作品：一念天下、羽境、海绵宝宝大战僵尸鱼、海底塔防、节拍失控！BEAT.exe 和 DOG WALK。《一念天下》目前为 v0.3.0 试玩版；具体平台、操作与下载以各项目详情为准。

网页、HTML 和 Windows 版有什么区别？

网页入口适合直接体验；提供单文件 HTML 的作品可下载后用浏览器离线打开。Windows 成品适合双击运行。存档方式因作品与平台而异，请查看项目详情；网页存档通常保存在当前浏览器。

想读文章，或者了解创作过程？

回到ChenC 博客按学习和生活分类阅读，或搜索文章。作品的「项目详情」保留设计思路和更新记录；全部作品目录提供完整的十个公开作品入口。
