# 已弃用的三维手办风格探索稿

当前会客室改用原版二维贴图配合景深、遮挡和投影的 2.5D 表现，不加载本目录模型。本目录只保留旧版本探索结果，不属于当前审核内容。

12 份 GLB 是根据 SOURCES.md 中的原版二维形象制作的简化 Q 版重建，非官方原始模型。背面和未见细节是重建设计。模型全由有体积的网格组成，无人物贴图平面。

每个文件包含 `Idle`（待机）、`Walk`（行走）、`Signature`（人物动作）三段 glTF 2.0 动画，关节通过父子层级连接。配色使用材质，模型没有图片纹理。GLB 可导入支持 glTF 的三维软件。

页面使用同源网格代码 `js/character-models.js`，模型由 `preview/export-character-models.mjs` 导出。manifest.json 列出模型名、网格数、动画及文件大小。完整参考出处见上级目录 SOURCES.md。

星穹：流萤、花火、火花、遐蝶、景元、知更鸟、星期日、砂金。
秦庭：嬴政、李斯、蒙恬、王翦。

会客室中模型由时间驱动自动走动和做动作，无用户控制器。角色的动作是页面设计的演绎，不是从游戏提取的官方动画。
