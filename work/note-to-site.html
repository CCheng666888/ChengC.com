笔记写完，一键变成网站文章

文章页的导语、大纲、思维导图每篇都要手工弄，重复劳动太多。于是做了这个 Obsidian 插件：当前笔记一键转成可直接发布的文章 HTML。

v1.1.0Obsidian 插件可下载插件

设计目的

自己维护网站，文章页的结构是固定的：标题、导语、正文、大纲，有的还要配思维导图。每写一篇都手工排版一遍，很重复。理想状态是——笔记在 Obsidian 里写完了，一键就能变成网站文章的 HTML，复制或保存后直接接入发布流程。

设计思路

在 Obsidian 里提供命令 + 侧边栏图标：读取当前笔记 → 生成文章页面 → 弹窗预览 → 选择「复制 HTML」或「保存到笔记库」。生成结果对齐本站文章模板：

  • 本地提取为主：导语默认取正文第一段截断，不联网也能生成；
  • 可选 AI 摘要：接任意 OpenAI 兼容接口（含本地 Ollama），让模型生成导语，失败自动回退本地提取；
  • 彩色思维导图：正文末尾自动生成，标题为中心、H2 一级分支（每支一色）、H3 二级分支，纯 CSS 实现、自包含。

实现过程

  • 用 TypeScript 写插件，esbuild 打包成 main.js，manifest.json / main.js / styles.css 三个文件放进 .obsidian/plugins/note-to-site/ 即可启用；
  • 把生成逻辑拆成纯函数（导语提取、大纲收集、思维导图树构建、frontmatter 解析、阅读时长估算、文件名转写），方便单独测试；
  • 用 smoke-test.mjs 写断言：覆盖导语首段提取、超长截断、空正文兜底、大纲层级、思维导图配色归属等；
  • 思维导图的可视化验证：用网站真实的 style.css 生成演示页，无头浏览器截图 + 像素取样，确认各分支颜色正常渲染。

遇到的困难

  • Obsidian 的渲染细节多：DOM 处理和 Markdown 转换的边界情况不少，把核心逻辑抽成纯函数之后才测得住；
  • 思维导图在明暗主题下的可读性：站点有明暗两套主题，导图最后固定为白底卡片、每支一色，保证两种主题下都清楚。

做了哪些优化

  • v1.1.0（当前）：补齐设置项（默认分类、导语最大字数、大纲/思维导图开关、站点名、样式表路径、保存文件夹），新增可选 AI 摘要（OpenAI 兼容 / Ollama），生成结果的完整性比首发版更好；
  • v1.0.0 首发：先跑通「本地提取 + 预览 + 复制/保存」的基本流程。

更新记录

  • v1.1.0（当前） 设置项 + 可选 AI 摘要

    补齐生成相关的配置项；导语可接 OpenAI 兼容接口（含本地 Ollama），失败自动回退本地提取。

  • v1.0.0 首发版

    本地提取导语、正文、大纲与彩色思维导图，弹窗预览后复制 HTML 或保存到笔记库。

下载与安装

下载后将 note-to-site 文件夹放到笔记库的 .obsidian/plugins/ 中，再在 Obsidian 的第三方插件里启用。预览思维导图效果可以直接打开演示页。
