比奇堡的同人小游戏：守住每一波僵尸鱼

喜欢海绵宝宝，也玩过植物大战僵尸，于是做了这个同人小游戏：抵御不断出现的僵尸鱼，挑战更高的分数。

v1.0Windows / 网页同人小游戏

设计目的

初衷很直接：把「植物大战僵尸」的防守玩法套到海绵宝宝的世界里，做一款同人小游戏——在比奇堡场景里抵御一波波出现的僵尸鱼，挑战更高分数。没打算做得很大，先保证「打开就能玩、能打出分数」。

设计思路

  • 玩法：类 PVZ 的防守玩法，僵尸鱼不断出现，玩家的目标是在守住的同时拿到更高分数；
  • 单文件承载：游戏本体做成单文件 HTML（约 3.6MB），网页直接打开就能玩；
  • 双入口：网页版在线试玩；Windows 版把同一份游戏打包成 EXE（约 20MB），双击即玩；网页版另有一个 Next.js 壳，带全屏按钮。

实现过程

  • 先做网页版玩法原型，跑通核心循环后，再打包 Windows 成品；
  • 素材单独整理：角色贴图、多张背景、应用图标放在素材目录，游戏成品里内嵌引用；
  • 进度用 JSON 存档保存在本地，并在存档结构变化时做迁移处理。

遇到的困难

  • 存档兼容：存档字段改过一轮，旧存档需要迁移、自动补齐新字段，处理不好会让玩家丢进度（当时专门留了迁移前的备份）；
  • 关卡退出异常：修过一次「退出关卡」相关的逻辑异常，改动前同样留了代码备份，方便对比回归；
  • 打包体积：Windows 成品约 20MB，主要是素材和运行时，属于能接受但偏大的水平。

做了哪些优化

  • 存档机制迁移过一次：旧存档自动补齐新增字段，避免读档失败；
  • 修复了关卡退出的异常逻辑，保证退出/重开流程稳定；
  • 提供「网页在线试玩 + Windows 成品下载」双入口，网页版支持全屏游玩。
