节拍失控！BEAT.exe

跟上节拍，连接你的频率。四轨下落式音游，带着八首原创音乐，邀请你在一次次挑战中找到自己的节奏。

v1.0.0音乐节奏游戏网页 / Windows

跟着音符，找到节奏

音符沿四条音轨落下，抵达判定线时操作。普通音符点击，长按音符按住至尾部，滑动音符沿提示换轨；键盘使用 D、F、J、K，手机直接触控音轨。根据时机获得 PERFECT、GREAT、GOOD 或 MISS，结算会记录分数、最大连击与通关评级。

从第一拍，到更高难度

八首原创曲目涵盖电子、氛围与摇滚风格，提供 EASY、NORMAL、HARD、INSANE 四种难度。通过游玩解锁曲目、背景、难度与特殊谱面，成就记录每一次突破。

进度会留在这里

网页会自动将成绩、解锁与设置保存在当前浏览器中，下次回来即可继续。游戏设置还支持导出和导入存档，方便备份或换设备。Windows 版也可以离线游玩。

设计目的

想做一个打开就能玩的节奏游戏：四条音轨、原创音乐、键盘和触屏都能操作，不依赖外部服务器，网页版与 Windows 版都能随时玩。

设计思路

  • 操作：音符沿四轨下落，普通音符点击、长按音符按住至尾部、滑动音符沿提示换轨；键盘使用 D、F、J、K，手机直接触控音轨；
  • 判定与结算：按时机给出 PERFECT、GREAT、GOOD 或 MISS，结算记录分数、最大连击与通关评级，成绩保存在当前浏览器；
  • 内容与解锁：八首原创曲目（电子、氛围与摇滚），EASY、NORMAL、HARD、INSANE 四种难度；通过游玩逐步解锁曲目、难度、背景与特殊谱面，成就记录每一次突破；
  • 双端：网页单文件内嵌音乐与图片，Windows 版可离线游玩。

实现过程

  • 游戏作为独立 HTML 交付：play/beat-exe.html 把音乐、图片与游戏代码全部内嵌，站内直接试玩，不跳转外部域名；
  • 专属像素节拍舞台：四轨下落音符、扬声器、动态均衡器与节拍灯，卡片和详情页共用同一套 beat 像素场景；
  • 进度、解锁与设置自动保存在浏览器本地，支持导出/导入存档；
  • Windows 成品与网页版共用同一套游戏内容。

遇到的困难

  • 音画同步：下落谱面最怕延迟，游戏设置里提供延迟校准，让判定线和音乐对齐；
  • 双操作适配：键盘四键与手机多指触控要共用同一套判定逻辑，触屏上多轨同时按下也需要单独处理；
  • 单文件体积：八首音乐和图片内嵌后文件较大，因此独立游戏不纳入主站预加载与页面缓存，需要时再打开。

做了哪些优化

  • 专属像素舞台：按反馈为音游增加独立 beat 背景，四轨音符、扬声器、动态均衡器与节拍灯随音乐变化；
  • 站内试玩：游戏页第五张卡片接入音游，封面为像素音轨，试玩与 Windows 下载都在本站完成，不跳外部；
  • 观谱练习：提供练习模式，熟悉谱面后再挑战正式成绩。
