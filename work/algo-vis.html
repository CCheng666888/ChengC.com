设计目的

阅读循环和变量时，容易跟丢数组当前的状态。把比较、交换和赋值放进同一个演示面板，让代码执行过程可以暂停、单步查看，再对照讲解理解每一步。

如何使用

  • VS Code：安装 VSIX 后选中代码，通过右键菜单、命令面板或 Ctrl+Alt+A 打开演示面板；支持 VS Code 1.70 及以上。
  • Obsidian：把插件放进笔记库的 .obsidian/plugins/algo-vis/ 并启用；可以选中代码，也可以使用 algovis 代码块或侧栏可视化台。
  • 网页演示：本站使用页提供实时冒泡排序演示与算法卡片，进入编辑器使用前可先查看效果。

当前功能

演示面板同步展示比较与交换动画、正在执行的代码行、变量状态和中文说明，提供播放、暂停、单步与 0.5×–4× 调速。支持识别 C、C++、Java、Python 的常见算法代码模式。

  • 8 种排序：冒泡、选择、插入、快速、归并、堆、计数、希尔排序。
  • 查找与窗口：二分查找、定长滑动窗口。
  • 数论与序列：试除法判素数、质因数分解、辗转相除 GCD、斐波那契数列。

识别与演示边界

内置引擎根据代码模式识别算法，并使用演示参数；可通过声明式写法设置算法和输入。未匹配内置算法时会进入通用代码步进模式。演示用于学习代码流程，具体输入规则和支持范围以本站使用页的说明为准。
