一段有自己节奏的散步

DOG WALK 是一款打开网页就能玩的遛狗小游戏：你带着一只狗狗在公园里散步，移动、遛狗、与狗互动、接飞盘、随机事件、分数、狗狗状态与成就组成了每一段散步。轻松、直接，不需要攻略也能玩得明白。

设计目的

让「遛狗」这个日常动作本身变得好玩：打开就能走，也可以停下来玩。小鸟、另一只狗、掉落的食物和一只飞盘，都可能改变这次散步的节奏。狗狗会好奇、兴奋、分心，也会累；一根牵引绳连接着两个各有想法的伙伴。

现在可以怎么玩

  • 移动与遛狗：WASD / 方向键自由移动；手机使用虚拟摇杆。三只性格不同的狗狗会跟随、探索、奔跑或休息，牵引绳限制彼此距离；
  • 与狗互动：抚摸、召回和休息，照顾快乐、体力、服从、好奇与信任五项状态；
  • 随机事件：发现飞盘、看见小鸟、遇到其他狗狗或路边食物时，选择不同的应对方式；
  • 三种小游戏：调整角度和力度扔飞盘，观察狗狗提示寻找骨头，快速选择坐下、过来、等待或握手；
  • 状态与结算：散步结束后按距离、互动和状态评出分数与星级，解锁正常成就，也可以重新出发。

进度会留在这里

  • 散步途中自动保存，刷新后可以继续；最高分、成就、累计散步次数、距离与信任记录保存在当前浏览器；
  • 设置中可调整音量与画面，也可以在二次确认后重置存档；
  • 直接打开站内试玩即可游玩。下载包包含游戏源码和本地素材，解压后运行 npm install、npm run dev；支持 npm run build 构建静态版本。
