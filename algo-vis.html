01 / INSTALL

安装方式

两个平台各自独立安装，互不影响。VS Code 版全局生效，Obsidian 版在笔记库内生效。

VS Code vscode

  1. 选中代码，在编辑器里框选一段算法代码
  2. 右键，点击菜单顶部的「算法动图：演示选中的代码」
  3. 右侧自动打开动画面板，自动播放
$ code --install-extension algo-vis-1.0.0.vsix
快捷键 Ctrl+Alt+A 可直接触发；也可在命令面板输入「算法动图」调用。支持 VS Code 1.70+，Windows / macOS / Linux 通用。
下载 VSIX 安装包内含使用说明 · 14.5 KiB

Obsidian obsidian

  1. 将插件目录放入库的 .obsidian/plugins/algo-vis
  2. 设置 → 第三方插件 → 开启「算法动图」
  3. 在笔记里选中代码，点击浮出的「演示算法」按钮
.obsidian/plugins/algo-vis/manifest.json
另有两个入口：代码块 algovis 声明式演示，以及左侧栏的「可视化台」图标。

02 / ALGORITHMS

支持的算法

引擎按代码模式自动识别，无需标注。内置 14 种经典算法（8 种排序全覆盖），覆盖排序、查找、数论、序列；识别不到特定算法时自动进入「代码步进模式」。

排序

冒泡排序

相邻两两比较，大的后移；每一轮末尾元素就位。演示会标出每一次比较与交换。

排序

选择排序

每轮扫描剩余部分找最小值，换到已排序区末尾，并高亮「当前最小」的更新过程。

排序

插入排序

取出 key 向左逐个比较，大于 key 的元素后移，最后插入正确位置。

排序

快速排序

选基准 pivot 分区，左小右大后归位，再递归处理左右子区间，演示每次比较与交换。

排序

归并排序

两两合并相邻有序块，用临时数组逐步归并：比较取较小者、写入结果、剩余直接并入。

排序

堆排序

把数组看作完全二叉树，建大顶堆后堆顶与末尾交换、再下沉，最大值逐个就位。

排序

计数排序

统计每个值的出现次数，前缀累加确定位置，从后往前稳定回填输出。

排序

希尔排序

按间隔 gap 分组做插入排序，gap 逐步减半，组内比较与后移清晰可见。

查找

二分查找

维护左右区间 [l, r]，每次取 mid 比较，区间不断减半直到命中或耗尽。

查找

滑动窗口

定长窗口沿数组滑动，演示滑出/滑入元素与窗口和的增量计算，跟踪最大值更新。

数论

试除法判素数

只需试到 √n，跳过偶数因子，逐个展示 i*i<=n 的优化边界。

数论

质因数分解

先除尽 2，再试奇数因子，输出每一步取出的质因数与剩余值 x。

数论

辗转相除 GCD

gcd(a,b)=gcd(b, a%b)，逐步演示取模、赋值、直到余数为 0 的全过程。

序列

斐波那契数列

前两项固定，之后每项等于前两项之和，逐项生成并高亮已计算区。

03 / QUICK START

快速上手

从选中代码到动画面板，三步完成。所有入口都是「选中即用」，不需要任何额外配置。

1

选中代码

在编辑器里框选一段算法代码。可以是完整函数，也可以只是一段核心循环。

2

触发演示

VS Code 里右键点「算法动图」；Obsidian 里点击选中区域浮出的演示按钮。

3

观看动画

面板自动播放：比较碰撞、交换滑动、代码行高亮、变量变化、中文讲解同步进行。

播放 / 暂停 · 单步 · 0.5x–4x
VS Code · 右键菜单

编辑器右键菜单顶部「算法动图：演示选中的代码」，仅在选中代码时出现。

VS Code · 快捷键 / 命令面板

Ctrl+Alt+A 直接触发；命令面板输入「算法动图」同样可调用。

Obsidian · 选中浮动按钮

选中代码后，选区旁浮出「演示算法」按钮，点击即演示；未知算法会提示并给出现可视化台兜底。

Obsidian · 代码块声明

代码块语言写 algovis，块内写「算法: 冒泡排序」和「数组: 6,2,9,1」，渲染时直接演示。

05 / INPUT & DETECTION

参数与自动识别

引擎会从选中代码里识别算法类型并采用演示参数；也可在选中内容中显式声明算法与输入。

声明式写法（Obsidian 代码块）

```algovis 算法: 冒泡排序 数组: 6,2,9,1,5 ```
```algovis 算法: 二分查找 数组: 1,3,5,7,9,11 目标: 7 ```

自动识别规则（部分）

冒泡a[j] 与 a[j+1] 比较双层循环且内层上限 n-1-i
选择min = i内层从 i+1 起扫描找最小值
插入key = a[i]while 向左移动元素
二分mid = (l+r)/2区间减半，比较 target
试除i*i <= n判素数函数
质因数while(x%i==0)循环除尽 + 输出因子
GCDgcd取模辗转，余数赋回
斐波那契f[i]=f[i-1]+f[i-2]递推生成
快速quickSort / partition函数名 + 递归分区
归并mergeSort / merge函数名 + 临时数组合并
堆heapSort / heapify函数名 + 建堆交换
计数countingSort / countSort函数名 + 计数数组
希尔shellSort函数名 + gap 分组插入

06 / FAQ

常见问题

右键菜单里没有「算法动图」怎么办？
菜单项只在选中了代码时才出现——先框选一段代码，再点右键。若仍不可见，确认扩展已启用（VS Code 扩展面板搜索 algo-vis；Obsidian 设置里开启「算法动图」），并重启窗口。
代码识别不出来 / 提示未知算法？
识别基于模式匹配，太片段化的代码可能匹配不上。解决：在选中内容里加一行声明，如 算法: 冒泡排序；Obsidian 还可改用代码块 algovis 并同时声明数组参数。识别不了也会进入「代码步进模式」演示执行过程，不会空手而归。引擎支持 C / C++ / Java / Python 的常见写法。
动画默认参数不是我想要的？
每个算法都有默认演示输入（如冒泡排序默认 5,3,8,4,2）。需要自定义时，在选中内容里写明，如 数组: 9,1,8,2,7（Obsidian 代码块写法）或 算法: 二分查找 / 数组: ... / 目标: 7。
播放速度能调吗？
可以。面板控制条提供 0.5x / 1x / 2x / 4x 四档调速，也可随时暂停、上一步、下一步、重置，逐帧理解每一步。
支持哪些语言？
引擎按算法结构识别，与语言弱相关。C / C++ / Java / Python 中实现这 14 种算法的常见写法都能识别，展示源码统一为 C 风格，便于对照学习。
我的代码不是这 14 种算法，能演示吗？
能。识别不到特定算法时，自动进入「代码步进模式」：逐行模拟执行（for/while/if 的循环推进、条件判断、变量增减、数组元素读写、break/continue、printf 输出），每一步都显示当前执行到哪一行、变量变成多少。适合看普通代码的循环到底怎么跑。
VS Code 版和 Obsidian 版有什么区别？
同一个动画引擎。VS Code 版面向所有项目，入口是右键 / 快捷键 / 命令面板；Obsidian 版面向笔记，多了「选中浮动按钮」「代码块声明」「左侧可视化台」三种笔记内入口。
