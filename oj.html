01 / 问题

小球何时、何处落地？

在水平地面上方，小球以初速度 v₀、与水平方向夹角 θ 抛出。质量为 m，初始高度为 h，重力加速度为 g。空气阻力满足 F阻 = −k v，方向始终与瞬时速度相反。

忽略风、浮力和地面碰撞后的运动。给定多组参数，输出小球首次落地的时间 t、水平距离 x 和落地前瞬间的速率 s。如果 h = 0 且竖直初速度为 0，约定立即落地，返回 t = x = 0、s = v₀；如果从地面向上抛出，计算再次落回地面的时刻。

02 / 物理与数学

从微分方程开始

令竖直向上为正。你可以从下面的方程推导位置和速度，再寻找高度变为 0 的时刻：

m · dvₓ/dt = −k vₓ
m · dvᵧ/dt = −mg − k vᵧ

vₓ(0) = v₀ cos θ    vᵧ(0) = v₀ sin θ
x(0) = 0            y(0) = h
推导提示

当 k > 0 时，令 q = k/m，先解一阶线性微分方程，再积分得到位置。高度函数在最高点之后严格下降，可用二分法求非负落地时间。注意地面向上抛出的起点不是要找的落地点。

当 k = 0 时用匀加速运动公式。很小的 qt 会导致相近浮点数相减丢失精度，可使用级数展开；Python/C 的 expm1、Java 的 Math.expm1 也有帮助。输出速率时需要同时考虑两个速度分量。

03 / 输入与输出

统一标准输入输出

第一行是整数 T（1 ≤ T ≤ 100）。随后 T 行，每行六个实数：

m k h v₀ θ g
参数单位和范围
参数单位范围
mkg0.1 ≤ m ≤ 100
kkg/sk = 0 或 10⁻⁶ ≤ k ≤ 50
hm0 ≤ h ≤ 1000
v₀m/s0 ≤ v₀ ≤ 1000
θ度0 ≤ θ ≤ 85
gm/s²1 ≤ g ≤ 20

每组输入输出一行 t x s（单位依次为 s、m、m/s），建议保留至少 6 位小数。每个数满足 |答案 − 标准值| ≤ max(10⁻⁶, 10⁻⁶ × |标准值|) 即视为正确。可以使用科学计数法；不要输出标签、提示或调试信息。
