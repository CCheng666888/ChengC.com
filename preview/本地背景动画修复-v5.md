# ChenC 本地背景动画修复 · 2026-10-03

用户反馈：交付的本地 HTML 与服务预览不同，首页背景无法播放动画。

代码中的兼容问题：原实现把 CSS 的 file:// 图片直接传入 WebGL 的 texImage2D。浏览器可能允许该图片作为 CSS 背景显示，却拒绝将它作为动画纹理读取。初始化异常被旧代码吞掉，页面便退回静态背景。此前仅覆盖了 HTTP 本地服务预览，未覆盖双击 HTML。

依据：[MDN WebGL 纹理与跨域限制](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Tutorial/Using_textures_in_WebGL)。这是源码与浏览器规则支持的诊断，尚未在用户实际浏览器的 file:// 页面复现。

## 修改

- 首页增加 `js/scene-images.js`：双击打开时，通过普通脚本加载原背景图片的 data URL，再交给 WebGL。无需 Fetch、网络服务或浏览器安全设置修改。
- `js/scene-day-data.js`、`js/scene-night-data.js` 与现有晨光和夜景图片逐字节一致。晨光先加载，夜景仍在切换时才加载。
- HTTP/HTTPS 页面继续直接加载原图片，不额外下载这两份兼容数据。
- 保留原水面透视、点击互动、山间云雾、鸟群与渔灯。主站布局、个人页及保险箱代码未调整。
- 增加图片失败与纹理失败提示；系统开启“减少动画”时，说明可点击“继续动画”播放。
- `index.html` 的脚本版本更新为 20261003，避免沿用旧版本。
