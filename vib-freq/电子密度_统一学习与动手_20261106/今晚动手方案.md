本文件夹的 `实践/运行结果` 保存你今晚的新结果。每次运行创建新子文件夹，旧算例保留。不要把下文演示的文件夹名原样当作自己的运行时间。

## 步骤 1：认识三种窗口，5 分钟

| 窗口 | 如何识别 | 可以输入什么 | 如何退出 |
| --- | --- | --- | --- |
| Windows PowerShell | 提示符常以 `PS D:\...>` 开头 | PowerShell 命令、.cmd 路径 | `exit` |
| Ubuntu 量化终端 | 由原量化终端入口打开；路径以 `/mnt/d/` 等开头 | `pwd`、`ls`、`python`、`xtb` | `exit` |
| Python 交互界面 | 提示符为 `>>>` | `import`、`print(...)` 等 Python 语句 | `exit()` |

**不要把提示符也复制进去。** 本方案的代码框没有 `PS>`、`$`、`>>>` 这些提示符，复制框内内容即可。在 Windows 中直接输入 `python` 可能启动另一个解释器；今晚从菜单打开已配好的量化终端。

1. 在“今晚动手菜单”按 **1**（无需回车）。
2. 新窗口会检查 NumPy、PySCF、Psi4、RDKit、Matplotlib、xTB，并算一个氢分子的 HF/STO-3G 小例子。
3. 看到各包 `PASS import ...`，最后出现 `PASS. Results:`，表示这一组检查完成。氢分子能量应在 **−1.1167593 Hartree** 附近。
4. 记下 `RUN_FOLDER:` 后的路径。Linux 的 `/mnt/d/电子密度综述/...` 对应 Windows 的 `D:\电子密度综述\...`。
5. 菜单按 **5** 打开结果文件夹，进入最新的 `check_...`，用记事本打开 `environment.json`。找到 `status: PASS` 和 Python 路径。窗口中的 JSON 也是同一份记录。

成功标准：导入检查、xTB 版本检查与氢分子计算都通过。只看到软件版本号，还不足以证明计算链条跑通。

若看到 `ModuleNotFoundError`，先看 Python 路径是否包含 `/edensity-tools/mamba/envs/qc/`。若是 Windows 的 Python，关闭该窗口，重新从本菜单启动。不要先执行 pip install。如果 WSL/Ubuntu 启动失败，先打开 Windows 开始菜单中的 Ubuntu，读末尾错误，保留 `console.log`。

## 步骤 3：先看懂水分子输入，5–10 分钟

1. 在资源管理器进入本资料的 `实践\inputs`。
2. 右键 `water.xyz`，选择“打开方式→记事本”。第一次只查看，不改数值。
3. 对照以下内容：第 1 行原子数，第 2 行说明，第 3–5 行是元素与三维坐标，单位为 Å。

```text
3
Water teaching geometry; Angstrom; charge 0; singlet
O  0.000000   0.000000   0.000000
H  0.000000  -0.757160   0.586260
H  0.000000   0.757160   0.586260
```

这是 3 个原子、10 个全电子的中性水。电子态设置在计算程序中明确指定，XYZ 的说明行本身不会自动设置程序电荷和自旋。

今晚主流程保留这份输入，便于核对。想研究改键长的影响，另存 `water_changed.xyz`，再单独设计同设置比较；不要在第一次运行中同时改几何、泛函、基组和电荷。

## 步骤 4：第一次 xTB 优化与振动，15–20 分钟

1. 回菜单，按 **2**（无需回车）。
2. 新窗口使用 GFN2-xTB，读取刚才的水分子，优化几何并计算 Hessian/振动。保留窗口，等到末尾出现 `PASS. Results:`。若窗口仍在打印或 CPU 忙，先等待。
3. 菜单按 **5**，进入最新的 `xtb_...` 子文件夹。
4. 用记事本打开 `xtbopt.xyz`，与输入的坐标比较。它是优化后的核坐标，不是电子密度。
5. 打开 `vibspectrum` 查看波数，打开 `result.json` 查看是否生成优化结构和振动文件。完整过程在 `xtb.out`。

程序实际执行的核心命令如下，在已进入含 `input.xyz` 的 Ubuntu 量化终端目录时可使用：

```bash
xtb input.xyz --gfn 2 --chrg 0 --uhf 0 --ohess
```

`--gfn 2` 选 GFN2-xTB；`--chrg 0` 表示电荷 0；`--uhf 0` 表示此处未配对电子数 0；`--ohess` 先优化，再做 Hessian。无需背住本机的全部安装路径。

水是非线性三原子分子，有 3 个内部振动模式。原始频率文件可能还显示接近零的平移/转动项，不能机械按全部行数数内部模式。用当前输出中的模式和频率，不照抄旧资料中的精确小数。xTB 总能量与全电子 DFT 总能量采用不同模型，分别记录方法与数值。

成功标准：`xtbopt.xyz`、`vibspectrum`、`xtb.out` 都存在且非空，并出现正常结束的结果记录。

## 步骤 5：用 PySCF 算单点能与电子密度，15–25 分钟

1. 菜单按 **3**（无需回车）。
2. 本练习在**步骤 3 的固定输入几何**上运行 PBE/def2-SVP，电荷 0、PySCF spin=0。它没有自动接用 xTB 优化坐标，因而不会把几何变化混进方法比较。
3. 窗口逐步打印 `SCF` 迭代能量。结束后找到 `converged: true`、`electron_count_from_density_matrix` 接近 **10**、`status: PASS`。
4. 菜单按 **5**，进入最新的 `pyscf_...`。
5. 先打开 `result.json`，再打开 `pyscf.out`，在日志中按 **Ctrl+F** 搜索 `converged`。保存 `density.cube` 和 `wavefunction.molden`，后面看图要用。

| 文件 | 你今晚要看什么 |
| --- | --- |
| result.json | 方法 PBE、基组、电子态、是否收敛、能量、电子数 |
| pyscf.out / console.log | 原始计算日志与迭代过程 |
| density_matrix.npy / overlap_matrix.npy | P 与 S，电子数按 Tr(PS) 检查 |
| density.cube | 64³ 空间采样点上的电子密度，单位 e/bohr³ |
| wavefunction.molden | 分子轨道与基组等信息，供可视化程序读取 |
| density_slice.png | 此次计算的二维密度切片，色标是 log10 密度 |
| scf_trace.json | 本次迭代能量记录 |

有限均匀网格积分 `finite_grid_electron_integral` 与矩阵给出的 10 可能有差别。先看网格范围、分辨率与积分方式；不要为了凑到 10 直接篡改文件。图中 x 切片坐标写在标题中，未保证恰好为 x=0。

成功标准：SCF 收敛、Tr(PS)≈10、密度数组有限、上述主要输出生成。

## 步骤 6：看见本次密度，并写下结果，15–20 分钟

接着看三维：

## 步骤 8：在 Jupyter 里亲手写最小计算，选做 15–20 分钟

1. 菜单按 **7**，等待浏览器打开。保留启动 Jupyter 的终端窗口。
2. 若浏览器没打开，复制终端打印的带 `token=` 的 `http://127.0.0.1:8890/...` 本地地址到浏览器地址栏。不要复制资料中的固定示例 token。
3. 在 Launcher 选择 Python 内核 **量化计算_Psi4_PySCF**，新建 notebook，重命名为 `我的第一次水分子.ipynb`。已有文件名不同也可，只要确认内核环境。
4. 在第一个代码格粘贴以下内容，按 **Shift+Enter**：

```python
import sys
print(sys.executable)
```

确认路径属于 `edensity-tools/mamba/envs/qc`。第二格输入：

```python
from pyscf import gto, dft, lib
lib.num_threads(2)
mol = gto.M(
    atom='O 0 0 0; H 0 -0.757160 0.586260; H 0 0.757160 0.586260',
    unit='Angstrom', basis='def2-svp', charge=0, spin=0
)
mf = dft.RKS(mol)
mf.xc = 'pbe'
energy = mf.kernel()
print('converged:', mf.converged)
print('energy / Hartree:', energy)
print('electron count:', (mf.make_rdm1() * mf.get_ovlp().T).sum())
```

再次按 Shift+Enter；左侧 `[*]` 表示运行中，结束后会变成数字。不要重复点击制造多个计算。这个最小格的数值容差使用 PySCF 默认设置，与菜单脚本的显式设置略有区别，检查到合理一致即可。

5. 按 Ctrl+S 保存。只关闭浏览器页签不会自动停止内核。可从左侧 Running 面板停止内核；今晚结束时在服务终端按 Ctrl+C，按提示确认停止。

## 必须记住的命令与快捷键

| 要记住 | 在哪里用 | 用途 |
| --- | --- | --- |
| `pwd` | Ubuntu 终端 | 看当前所在目录 |
| `ls` | Ubuntu 终端 | 看当前目录有哪些文件 |
| `cd '路径'` | Ubuntu 终端 | 进入目录，路径有空格时引号尤其重要 |
| `python 文件.py` | Ubuntu 量化终端 | 运行一个 Python 脚本 |

| `exit` | Ubuntu / PowerShell | 退出当前终端层 |

需要认得、可以随查：`--gfn 2`、`--chrg`、`--uhf`、`--ohess`、`basis`、`mf.xc`、`charge`、`spin`。xTB 的 `--uhf` 与 PySCF 的 `spin` 是各自接口约定，不能把“单重态 multiplicity=1”直接当成“PySCF spin=1”。

## 遇到问题：按现象处理

| 现象 | 先做什么 | 本次要留下的证据 |
| --- | --- | --- |
| 窗口一闪而过 | 从菜单重开；本菜单的计算窗口会保留并显示返回码 | 错误末尾与结果目录 |
