理解自测与易混概念

训练 loss 持续下降，就说明模型可以推广吗？

不能。它表示模型更贴合训练目标，泛化能力要结合验证/测试集结果、数据划分和误差分析判断。

CrossEntropyLoss 前需要先做 Softmax 吗？

通常直接传入 logits。该损失内部已包含相关归一化计算；需要展示概率时，可在推理阶段单独转换。

RO5 有五个指标吗？

常用表达有四项阈值，围绕 5 的倍数命名。可旋转键 ≤ 10 属于这里单列的 Veber 条件。

聚类结果一定说明药效相同吗？

聚类说明在所用表示和度量下结构相近。相似结构不保证相同活性，活性悬崖等情况需要标签和实验检验。

MolCLR 的训练是否完全不用标签？

其预训练利用无标签分子构造对比信号，下游微调仍使用任务标签。比较结果时要完整交代这两个阶段。

MCS 搜索超时后，返回结构一定最大吗？

不一定。需要检查 canceled 标志，明确当前返回结果是否在已完成搜索中得到，以及是否已确认最优。

密度图更精细，是否表示 SCF 计算更精确？

导出网格与 SCF 内部积分网格分别设置。固定密度矩阵时，加密导出网格主要改变场采样与积分近似。

电子密度的旋转对称性怎样表达？

作为空间标量场，密度随分子旋转和平移；对应变换后的空间点具有相同数值。

QM9 性质预测是否已经训练了电子密度模型？

需要查看实际标签与输出。常规属性任务使用性质标签；密度模型还需参考场或相应表示标签。

拥有 10 个电子的预测密度就准确吗？

电子数约束只核验总量，局部分布与空间误差仍需检查。

作者模块导入成功是否复现了论文精度？

导入检查验证软件执行；模型推理、训练和论文指标复现各需要相应权重、数据与评价证据。

本次补充 · E4

SMILES 与 RDKit：结构如何进入程序

SMILES 用文本描述分子的原子、连接和部分立体化学信息。RDKit 把 SMILES 解析为分子对象，进而计算描述符、生成指纹、绘制结构和进行匹配。

CCO乙醇的一个 SMILES 示例

整理澄清：同一分子可以有多种有效 SMILES。canonical SMILES 是指定工具和规范化流程生成的标准形式；比较数据前仍需明确盐、互变异构体和立体化学的处理规则。SMILES 本身也不提供唯一的三维构象。

分子操作的最小示例

S6 · 第 7–8、15–16 幻灯片

以下为重新整理的代码示例：解析两个分子，计算乙醇的部分描述符，并比较 Morgan 指纹。需要先在项目环境安装 RDKit。

python
from rdkit import Chem, DataStructs
from rdkit.Chem import Descriptors, Lipinski, rdFingerprintGenerator

mols = [Chem.MolFromSmiles(s) for s in ["CCO", "CCCO"]]
if any(m is None for m in mols):
    raise ValueError("存在无法解析的 SMILES")

mol = mols[0]
print("标准 SMILES:", Chem.MolToSmiles(mol))
print("MW:", Descriptors.MolWt(mol))
print("LogP:", Descriptors.MolLogP(mol))
print("HBD / HBA:", Lipinski.NumHDonors(mol), Lipinski.NumHAcceptors(mol))

generator = rdFingerprintGenerator.GetMorganGenerator(radius=2, fpSize=2048)
fps = [generator.GetFingerprint(m) for m in mols]
print("Tanimoto:", DataStructs.TanimotoSimilarity(fps[0], fps[1]))

对二进制指纹，Tanimoto 衡量共有位占并集的比例。不同指纹定义和参数会改变相似度，比较前应统一设置。

Butina 根据邻居数量选择中心，将阈值内的邻居分配到同一簇，再处理剩余分子。用途包括去除冗余、选择代表性分子及组织化合物库。聚类内成员与中心相近，不保证任意两个成员都同样相近。

影响卷积输出尺寸的主要参数包括 kernel_size、stride、padding、dilation。普通 Conv2d 单个空间方向的尺寸公式为：

输出尺寸 = ⌊(输入尺寸 + 2p − d(k − 1) − 1) / s + 1⌋

k 是卷积核尺寸，p 是填充，d 是 dilation，s 是步幅。例如输入 28、k=3、p=1、s=1、d=1，输出仍为 28。公式依据 Conv2d 官方文档 核对。

不变性、等变性与电子密度场

本次补充 · E7

先用“把水分子转一下”理解对称性。总能量作为标量应保持不变；向量随旋转变换；电子密度作为空间标量场，其空间分布随分子一起移动和旋转。

ρRX+t(Rr+t) = ρX(r)

X 是核坐标集合，R 是旋转，t 是平移。对应空间点的密度值相同；固定实验室网格上的整幅密度图会随分子改变。相同元素原子的编号重排也应保持最终物理预测一致。

用 e3nn 的小例子认识标量、向量与表示，做一次数值对称性检查。e3nn 是构建等变网络的库；NequIP/MACE 的常用任务是原子势与力。把它们用于密度任务时，还要设计适合密度的输出表示、标签和约束。
