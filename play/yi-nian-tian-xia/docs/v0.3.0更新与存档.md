# 《一念天下》v0.3.0 — 多回合与存档兼容

日期：2026-10-06（北京时间）。仅本地更新，不部署、不推送。范围仍为教程、第一章、第二章。

## 玩法

教程24步、4回合：人物与情报、预算与撤回、资源与谋略、权柄与执行者、回报与最终验收。每类卡牌分别解释用途、限制和组合例子，并实际使用。第一章5回合处理消息、接应、藏身、转移与交接；第二章5回合处理核账、候选人、任命、执行与回执。

共14回合、34条可行解法。回合开始恢复行动点，线索、关系和资源库存不恢复。未达成小目标不推进，允许补救但风险+1；全部大目标核验完成才写入完成记录、解锁下一章。情报选中只是计划，执行成功才验证；时间库存执行时才消耗。

## 存档保证与边界

游戏版本0.3.0；存档schema从1升为2。网页固定使用 `yinian-tianxia-save-v1`，不随游戏版本换键、不自动重置。

升级保留已完成/解锁章节、当前关卡、历史、标签、关系和数值。旧版没有回合状态，未完成旧关卡从新版第1回合开始；旧完成记录仍承认。升级原档保存在 `.migration-v1`；写入保留 `.backup`，使用 `.pending` 完整写入日志，并恢复较新的中断写入。

新版额外保存回合、小目标标记、执行记录、资源库存、教程步骤和待执行选牌。未知较新schema不自动降级；损坏无可用备份时暂停写入，不用新档覆盖。禁用存储、配额用尽、多窗口冲突会提示，不假报保存成功。导入和重置须确认，确认前验证文件、备份现有原档。

Windows权威存档为 `%LOCALAPPDATA%\一念天下\saves\campaign.json`，与启动端口、EXE版本无关。临时文件原子替换，保留 `.backup`、首份 `.before-upgrade`，导入/重置/切换前另归档。素材包不含用户存档目录。原 `browser-profile` 不删除。

旧Windows版随机端口的localStorage不删除，但不能承诺自动找到所有旧地址。若原页面仍能打开进度，可在原页开发者工具执行 `localStorage.getItem('yinian-tianxia-save-v1')`，把结果保存为JSON导入新版。网页、离线HTML和Windows存储不自动共享，用JSON导入/导出转移。浏览器数据清理和磁盘损坏不能靠前端恢复，请定期导出到其他目录。

## 构建与验证

源文件为 `index.html`、`content.js`、`engine.js`、`app.js`、`rounds.css`。

```powershell
node tools/yiniantianxia/test_rounds.cjs
python tools/yiniantianxia/build.py --sync-site
node tools/yiniantianxia/test_browser.cjs
```

`--sync-site`仅同步相邻网站本地目录，不推送。站点介绍修改后需运行网站 `preview/build-delivery.cjs`。

逻辑测试穷举737种合法组合，444种拒绝推进；检查34条路线、预算、库存、缺失最终条件及旧档兼容。浏览器检查24步教程、完整14回合、无刷新出牌、中途刷新、导入确认、原档备份、损坏恢复、未知版本保护、多窗口冲突、备用图片与重试、独立HTML无外部请求、320/390px。EXE `--smoke-test`在独立临时目录测试启动、磁盘读写、备份、归档与换端口读取，不访问玩家存档。
