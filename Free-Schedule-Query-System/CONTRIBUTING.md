# 贡献指南

欢迎为「计算机学院第七届新媒体中心 · 空课查询系统」贡献代码与数据。本项目为纯前端单文件页面 + 一个数据转换脚本，贡献流程简单。

## 提交流程

1. **Fork** 本仓库并克隆到本地。
2. 创建分支：`git checkout -b feature/你的改动`
3. 做出修改，并**同步更新相关文档**（README / CHANGELOG / CONTRIBUTING 等），保持文档与代码一致。
4. 本地自测（见下），确认通过后提交 Pull Request。

## 常见改动类型

| 改动类型 | 需要改什么 | 自测方式 |
| --- | --- | --- |
| 更新空课数据 | 改 Excel 后运行 `python tools/convert_xlsx.py` | 打开 `index.html` 抽查若干时段 |
| 新增人员 / 调整分组 | 改 Excel（红色=干部，黑色=干事）后同上 | 检查头部统计人数与名单 |
| 修改页面样式 / 交互 | 直接编辑 `index.html` | 桌面与手机宽度各检查一遍 |
| 修改解析逻辑 | 编辑 `tools/convert_xlsx.py` | 运行 `python tools/verify_query.py` 回归 |

## 自测要求

- **数据类改动**：`python tools/verify_query.py` 输出无异常，且抽查的若干时段结果与 Excel 手算一致。
- **样式类改动**：桌面（≥1024px）与手机（≤390px）宽度下页面无横向滚动、下拉可展开、结果正确渲染。
- **逻辑类改动**：至少覆盖「全有空」「部分有空」「本组无人有空」三种结果形态；涉及全天查询时额外验证**交集语义**（只显示当天 5 课节都有空的人）与「该日无人全天有空」提示；涉及课节查询时额外验证**相邻时段备注**规则（见 README「相邻时段备注规则」）；涉及多选时额外验证**交集查询**、**边界相邻备注去重**与「有空」绿 /「有课」红着色；涉及值班时额外验证**值班行**（单周/双周与无人值班日）与名单中值班干事**整行黄色高亮**。

## 约定

- 页面保持单文件自包含：样式与逻辑内嵌 `index.html`，不引入构建工具与外部依赖。
- 数据更新一律通过 `tools/convert_xlsx.py` 生成，不手工改内嵌数据块（避免两边不一致）。
- 提交信息建议：`<类型>: <简述>`，类型取 `feat` / `fix` / `docs` / `refactor` / `data`。

## 变更记录

每次对项目产生可见变化的修改，请同步在 [CHANGELOG.md](CHANGELOG.md) 中追加一条记录。
