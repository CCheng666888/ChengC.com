# 变更记录

本项目遵循「可读、可追溯」的变更记录约定：每次对项目产生可见变化的修改，都会在此追加一条记录，并同步更新 README 等文档。

## [0.5.1] - 2026-09-14

### 变更
- 值班干事的标识方式调整：由名字旁「值班」小标记改为**所在整行黄色高亮**（与顶部值班行同款金色渐变），删除 `duty-tag` 标记
- 顶部「值班：XXX」行保持不变；`tools/ui_interaction_test.py` 用例 11 同步改为断言 `on-duty` 行高亮类与渐变背景

## [0.5.0] - 2026-09-14

### 变更（全天交集 + 值班表）
- **全天查询改为交集语义**：不选课节查询一整天时，只显示当天 5 个课节**都有空**的人（与多选交集一致）；当天无人全天都有空时提示「该日无人全天有空」（不再列出部分时段有空的人并标注空闲课节）
- **新增干事值班表**：按单周/双周 × 周一至周日排班（双周周日无人值班），数据内嵌为 `index.html` 的 `DUTY` 常量，与空课表相互独立
- 查询结果**顶部新增「值班：XXX」一行**，输出当天值班的干事；当天无人值班则不输出该行（全有空 / 无人有空等结果形态下依然显示）
- 名单中**当天值班的干事**名字旁新增金色「值班」标记，与非值班干事区分

### 新增 / 更新
- `tools/ui_interaction_test.py` 扩展至 **12 个用例**：改写全天用例为交集语义（无人全天有空 + 值班行、全有空 + 值班行），新增值班行/值班标记、双周周日无值班不输出
- `tools/verify_query.py` 新增 2 个全天交集（5 课节全选）抽样用例
- README 新增「值班表（干事）」一节，全天查询说明更新

## [0.4.0] - 2026-09-14

### 变更（课节多选）
- **课节下拉支持多选**：面板内可同时勾选多个课节（顶部有「可多选课节」提示），选中后在触发器上以「、」拼接显示；点「全天（不选）」清空选择恢复全天查询
- 查询结果改为输出**所选课节都有空**的人员名单（交集语义）：多选第1、2节与第3、4节时，只保留这两节课都空闲的人
- **相邻时段备注改为「边界相邻」规则**：按所选课节的连续段取边界外相邻课节，不再逐节重复备注——选中整个上午只备注第5、6节；非连续多选自动去重
- 备注中的「有空」显示为**绿色**、「有课」显示为**红色**
- 查询结果头部在课节多选时按「第1、2节、第3、4节（上午、下午）」格式展示所选节次与所属时段

### 新增 / 更新
- `tools/ui_interaction_test.py` 扩展至 **10 个用例**：新增多选整个上午（全有空）、多选交集 + 边界相邻备注 + 红绿着色、非连续多选备注去重
- `tools/verify_query.py` 新增 3 个多选交集抽样用例
- README「相邻时段备注规则」改写为单选 + 多选两套说明

## [0.3.0] - 2026-09-14

### 变更（相邻时段备注）
- 课节按 **上午 / 下午 / 晚上** 分组显示：第1、2节与第3、4节=上午，第5、6节与第7、8节=下午，第9、10、11节=晚上（下拉面板分组标题 + 查询结果头部标注）
- 查询某课节时，改为**备注相邻时段是否有空**（不再输出「该时段空闲周：…」）：
  - 第1、2节 → 备注第3、4节
  - 第3、4节 → 备注第1、2节与第5、6节
  - 第5、6节 → 备注第3、4节与第7、8节
  - 第7、8节 → 备注第5、6节与第9、10、11节（第7、8节原写为查第3、4节，经确认为笔误，按第5、6节执行）
  - 第9、10、11节 → 备注第7、8节
- 相邻时段有课则备注「有课」（不输出教室）
- 全天查询逻辑不变：一人一行标注当天空闲课节

### 新增
- `tools/ui_interaction_test.py` 扩展至 7 个用例：新增相邻时段备注断言（含 3、4 节与 7、8 节规则）、上午/下午标注、不再输出空闲周

## [0.2.0] - 2026-09-14

### 变更（界面改版）
- 去掉顶部「共 18 人 / 干事 / 干部 / 20 周」统计信息
- 标题与副标题居中显示，页面整体背景改为蓝色渐变
- 三个竖向选项列表改为**一行排列的下拉选择器**：周数、星期、课节（点击后纵向展开选项面板）
- 改为点击「查询」按钮后才输出结果；周数、星期必选，课节可不选（不选 = 查询一整天）
- 干部不再标红，与干事样式一致（仍先干事、后干部分组展示）
- 结果名单一人一行：选课节时标注该时段空闲周，全天查询时标注当天各空闲课节
- 新增必填校验提示（未选周数/星期时点击查询给出提醒）
- 移动端下拉触发器触控高度提升至 44px+，适配横滑与按钮换行

### 新增
- `tools/ui_interaction_test.py` 改为驱动新版下拉 + 查询按钮交互，覆盖必填校验、单选课节、全天、全有空、样式一致等 6 个用例

## [0.1.0] - 2026-09-14

### 新增
- 首个可用的单文件 HTML 空课查询页面（`index.html`）
  - 三个竖向选项栏：周数（1–20）、星期（周一至周日）、课节（第1、2节 … 第9、10、11节）
  - 查询结果先展示干事（黑色）后展示干部（红色），全员空闲时显示「全有空」
  - 响应式布局：桌面为竖向列表（周数可滚动），手机为横向滑动选项
- 数据解析工具 `tools/convert_xlsx.py`
  - 读取《计算机学院第七届新媒体中心空课表.xlsx》，自动识别红色（干部）/ 黑色（干事）
  - 兼容全角/半角标点、区间写法（如 `1，5-6，15-20`）与少量笔误（多余括号、双逗号）
  - 自动重写 `index.html` 内嵌数据块并导出 `data/schedule.json`
- 查询逻辑抽样验证脚本 `tools/verify_query.py`，以及真实浏览器交互测试 `tools/ui_interaction_test.py`（可选，需 playwright）
- 开源文档：README、LICENSE（MIT）、CONTRIBUTING、CHANGELOG、.gitignore

### 数据
- 初始化 18 人空课数据：干事 13 人、干部 5 人，共 7 天 × 5 课节 = 35 个时段格子
- 全部格子解析完整性与身份（干事/干部）一致性校验通过
